# Hey, I'm a curious builder. 👋

I enjoy exploring the intersection of **physics, engineering, computation, and biology**.

I'm fascinated by how complex systems work — from physical phenomena to mathematical models, from simulations to real-world applications.

### 🔬 Things I'm curious about

- **Physics & Engineering** — Understanding the mechanisms behind complex systems.
- **Scientific Computing** — Numerical modeling, simulation, and reduced-order models.
- **AI & Machine Learning** — Making intelligent tools useful for scientific discovery.
- **Building Things** — Turning ideas into prototypes, software, and occasionally something tangible.

### 🛠️ How I like to work

- First principles over black boxes.
- Elegant models over unnecessary complexity.
- Reproducible experiments over pretty plots.
- Working prototypes over endless discussions.

### 🧠 A little philosophy

> Stay curious. Think deeply. Build relentlessly.

I believe some of the most interesting ideas happen at the boundaries between disciplines — where a physicist starts thinking like a programmer, an engineer starts asking biological questions, and an unexpected connection turns into a new project.
